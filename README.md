## Sobre mim

Desenvolvedora Full Stack formada em Ciência da Computação pela **Universidade Vila Velha (UVV)**, com experiência em aplicações web e mobile, APIs REST e integração frontend/backend.

Minha trajetória inclui atuação como **Desenvolvedora ABAP Trainee** (Megawork Consultoria), desenvolvimento e manutenção de aplicações web com suporte em infraestrutura e cloud (PVT Software), testes de aplicações (Jade Autism) e soluções de realidade virtual para treinamentos corporativos (Vale/UVV). Atuo também como **freelancer**, conduzindo projetos de ponta a ponta — do levantamento de requisitos à entrega.

Construo produtos com **React, TypeScript e Node.js**, modelagem relacional com **Prisma/PostgreSQL/MySQL** e, no ecossistema corporativo, **SAP ABAP, Fiori/UI5 e SAP Build Apps**. Paralelamente, aprofundo estudos em **cibersegurança, cloud e DevSecOps**, aplicando mentalidade de desenvolvimento seguro no código que escrevo.
